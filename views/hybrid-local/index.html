Perplexity app (Personal Computer and Portable Computer)

On this page as desktop app. Also as hosted or cloud agent, on the page Hybrid as a cloud service.

On Mac, the app, files, app control and the local model run on the machine; planning, web search, reasoning and cloud models run in Perplexity's cloud. On Windows and Linux with supported hardware, the model and agent run on the machine and single steps go to the cloud only with approval.

  • Hardware: Mac: Apple silicon, macOS 15 or later, 24 GB unified memory minimum (the page says 32 GB gives better results). Windows and Linux (Portable Computer): an NVIDIA RTX or RTX PRO card with at least 24 GB of video memory, or a DGX Spark; on Windows, per the Personal Computer page only (see By page), an AMD Ryzen AI Max processor with at least 24 GB of GPU-accessible memory
  • Plan: Local models: Pro, Max or Enterprise. Portable Computer: Pro or Max, personal or Enterprise
  • Scope: Hybrid compute is Mac-only; with Portable Computer, Windows and Linux machines run the task on the device and send single steps to the cloud only with the user's approval
  • By page: The Portable Computer page (read 2026-10-22) names only NVIDIA hardware and offers Qwen 27B on supported Windows and Linux PCs; the Personal Computer page (read 2026-10-22) adds AMD Ryzen AI Max on Windows and limits Qwen 27B to AMD and DGX Spark.

Claude Code with a local server

This section is about pointing Claude Code at a model server that runs on your own machine.

Anthropic's statement

  • The Claude Code gateway page says Anthropic provides no support when a gateway sends Claude Code's requests to models that are not Claude, whichever gateway it is, and that Anthropic neither endorses, maintains nor audits gateway products made by others. (code.claude.com page, read 2026-10-21)

The pages do not say whether this statement covers a local model server, and we do not say either.

The setting Claude Code uses

  • The gateway page names ANTHROPIC_BASE_URL as the setting that sends Claude Code's requests to a gateway. (code.claude.com page, read 2026-10-21)

What each page says

  • Ollama links Claude Code with local and cloud models using its Anthropic-compatible API. (docs.ollama.com page, read 2026-10-21)
  • LM Studio's blog post says version 0.4.1 introduced an endpoint at /v1/messages that follows Anthropic's format, and that local models can be used with Claude Code through it. (lmstudio.ai page, read 2026-10-21)
  • Under its POST /v1/messages heading, the llama.cpp server README says compatibility with Anthropic's API specification is not strongly claimed, and that in the authors' experience the endpoint is enough for many apps. (github.com page, read 2026-10-21)
  • The oMLX README lists a POST /v1/messages endpoint described as the Anthropic Messages API, next to OpenAI-style endpoints on the same server. (github.com page, read 2026-10-21)
  • The MLX-LM server document says its HTTP API is meant to resemble OpenAI's chat API. An Anthropic Messages endpoint and Claude Code are not found in that document, the only page read. (github.com page, read 2026-10-21)
