How to read it

  • Follow the full-width boxes from top to bottom. You use a coding agent or assistant. It runs on an agent framework, which reaches company knowledge and tools and sends each request to a model, directly or through an optional gateway or proxy.
  • The indented box joined to a step by a dashed arrow works next to it: code review checks what the agents change, sandboxes give each run a safe place, and skills and specs hold the instructions the agents follow.
  • Models run in one of two places. Model hosting is a server you run, on your own machine, in a container or in your own cloud account; a cloud provider runs its models on its own servers. The hybrid pages follow what you have to run: Hybrid on your own machine for what you install, Hybrid in a container environment you run for services in containers and inference servers, with the container step drawn, and Hybrid as a cloud service for what the vendor runs.
  • The band at the bottom holds the four layers that touch the whole stack: testing agent output, catalogs and registries, distribution to teams, and security and secrets.
