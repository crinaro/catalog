Perplexity app (Personal Computer and Portable Computer)

On this page as hosted or cloud agent. Also as desktop app, on the page Hybrid on your own machine.

On Mac, the app, files, app control and the local model run on the machine; planning, web search, reasoning and cloud models run in Perplexity's cloud. On Windows and Linux with supported hardware, the model and agent run on the machine and single steps go to the cloud only with approval.

  • Hardware: Mac: Apple silicon, macOS 15 or later, 24 GB unified memory minimum (the page says 32 GB gives better results). Windows and Linux (Portable Computer): an NVIDIA RTX or RTX PRO card with at least 24 GB of video memory, or a DGX Spark; on Windows, per the Personal Computer page only (see By page), an AMD Ryzen AI Max processor with at least 24 GB of GPU-accessible memory
  • Plan: Local models: Pro, Max or Enterprise. Portable Computer: Pro or Max, personal or Enterprise
  • Scope: Hybrid compute is Mac-only; with Portable Computer, Windows and Linux machines run the task on the device and send single steps to the cloud only with the user's approval
  • By page: The Portable Computer page (read 2026-10-22) names only NVIDIA hardware and offers Qwen 27B on supported Windows and Linux PCs; the Personal Computer page (read 2026-10-22) adds AMD Ryzen AI Max on Windows and limits Qwen 27B to AMD and DGX Spark.
