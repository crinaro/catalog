Claude Code

A coding agent from Anthropic, run in a terminal or an editor, that holds the conversation, chooses which tools to call, runs commands and manages its own context until the work is done or it stops to ask.

The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the vendor's page.

Local and cloud models in one session

  • When model discovery is active, Claude Code contacts the gateway to retrieve available model names at startup, then lists them in the /model picker next to the built-in options. (code.claude.com page, read 2026-10-19)

What you set up

  • On Claude Code's gateway connection page, the gateway address and the credential variable chosen in an earlier step are both supplied through environment variables. (code.claude.com page, read 2026-10-19)

Models from different providers in one session

  • Claude Code's subagents page says a subagent's model field can be set to an alias, one of sonnet, opus, haiku or fable. (code.claude.com page, read 2026-10-21)

Plan or account

  • Claude Code's legal and compliance page says OAuth authentication is intended only for people who bought a Claude plan, whether Free, Pro, Max, Team or Enterprise, and is designed to cover everyday use of Claude Code and Anthropic's other native applications. (code.claude.com page, read 2026-10-21)
  • Anthropic's support article says that when an ANTHROPIC_API_KEY environment variable is set on the machine, Claude Code authenticates with that key rather than with a Pro, Max, Team or Enterprise subscription, so usage is billed as API usage instead of drawing on what the subscription includes. (support.claude.com page, read 2026-10-21)

Claude Code with a local server

  • The gateway page names ANTHROPIC_BASE_URL as the setting that sends Claude Code's requests to a gateway. (code.claude.com page, read 2026-10-21)
  • The Claude Code gateway page says Anthropic provides no support when a gateway sends Claude Code's requests to models that are not Claude, whichever gateway it is, and that Anthropic neither endorses, maintains nor audits gateway products made by others. (code.claude.com page, read 2026-10-21)

Plan, policy and billing

  • Claude Code's page on connecting to a gateway says a user who relies on the built-in models does not need gateway model discovery, and that an administrator may already have enabled it through managed settings. (code.claude.com page, read 2026-10-19)

A separate model for planning and for doing

  • Claude Code's model configuration page says that with the opusplan alias, opus is used while in plan mode, for difficult reasoning and architectural decisions. (code.claude.com page, read 2026-10-19)

About the product

  • Claude Code's overview page names four surfaces it runs on: a terminal, IDE extensions, a desktop application and a web version. (code.claude.com page, read 2026-10-24)
  • Claude Code's overview page says its scheduled tasks created as cloud tasks run in the cloud and keep going when the user's computer is off. (code.claude.com page, read 2026-10-24)
