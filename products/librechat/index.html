The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-20 to 2026-10-24); confirm on the vendor's page.

Local models

  • Ollama can run open models locally and expose an OpenAI-compatible API, so the customer can point LibreChat at their own machine. (www.librechat.ai page, read 2026-10-20)

Cloud models

  • LibreChat's custom-endpoints page says services that follow the OpenAI API format can be added as custom endpoints, as can Anthropic-style ones; its examples name OpenRouter, Ollama, and gateways that follow Anthropic's API format. (www.librechat.ai page, read 2026-10-20)

Models from different providers in one session

  • In LibreChat's agent builder, each agent has a Model setting for choosing among the available providers and models. (www.librechat.ai page, read 2026-10-21)

Plan, policy and billing

  • LibreChat's configuration page says its Admin Panel manages the librechat.yaml settings in a browser, including overrides for each role and group that apply when a user logs in, with no restart. (www.librechat.ai page, read 2026-10-23)
  • LibreChat's custom endpoints page says a 402 Payment Required from an OpenRouter endpoint usually means the problem sits on the OpenRouter account: credits, billing or which models it offers. (www.librechat.ai page, read 2026-10-23)

About the product

  • LibreChat's Docker page names Docker Compose as the preferred install method for most scenarios. (www.librechat.ai page, read 2026-10-24)
