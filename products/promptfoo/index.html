The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-20 to 2026-10-24); confirm on the vendor's page.

Local models

  • promptfoo's Ollama page says an Ollama model can act as the local grader for test assertions that require a language model to evaluate them. (www.promptfoo.dev page, read 2026-10-20)

One sentence naming both a local and a cloud path

  • promptfoo allows comparing models side-by-side, including OpenAI, Anthropic, Azure, Bedrock, and Ollama. (github.com page, read 2026-10-20)

What a local model must meet

  • promptfoo's Ollama page says context windows are small for embedding models, with all-minilm defaulting to 256 tokens and topping out at 512. (www.promptfoo.dev page, read 2026-10-23)
  • promptfoo's Ollama page says small models are handy for trying out a config without a big download, naming qwen3:0.6b, about 500MB, which handles tools and reasoning. (www.promptfoo.dev page, read 2026-10-23)
  • promptfoo's Transformers provider page says that on limited RAM, running promptfoo eval with -j 1 runs the evals one at a time. (www.promptfoo.dev page, read 2026-10-23)

Plan, policy and billing

  • promptfoo's Anthropic page says requests sent with a Claude Code login are expected to draw on your Claude subscription as Claude Code CLI calls do, and points readers to Anthropic's own documentation on current billing. (www.promptfoo.dev page, read 2026-10-23)
  • Anthropic's legal and compliance page says Anthropic does not allow third-party developers to offer a Claude.ai login in their own apps, or to send their users' requests through credentials from a Free, Pro or Max plan. (code.claude.com page, read 2026-10-23)
  • Anthropic's legal and compliance page says OAuth authentication is intended only for people who bought a Claude plan, whether Free, Pro, Max, Team or Enterprise, and is meant for everyday use of Claude Code and Anthropic's other native applications. (code.claude.com page, read 2026-10-23)
  • Anthropic's legal and compliance page says developers whose products or services use Claude, those built on the Agent SDK among them, should use API keys, whether from Claude Console or from a cloud provider Anthropic supports. (code.claude.com page, read 2026-10-23)
  • Anthropic's legal and compliance page adds that these limits do not stop an end user from logging in to an unmodified copy of Claude Code with that user's own Claude plan, even on a platform that hosts Claude Code. (code.claude.com page, read 2026-10-23)

A separate model for planning and for doing

  • promptfoo's prompt optimization page says the provider you select is the one being optimized, and promptfoo's default suggestions provider, not that selected provider, writes the candidate prompt rewrites. (www.promptfoo.dev page, read 2026-10-23)

About the product

  • promptfoo's README says its LLM evals run entirely locally and that prompts never leave the user's machine. (github.com page, read 2026-10-24)
