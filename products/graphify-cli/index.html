Graphify CLI

A Python CLI that parses a codebase into a knowledge graph on your machine with tree-sitter and writes a queryable graph file and an HTML visualization instead of a vector index.

The readings behind this page

Our summary of the vendor's pages as of 2026-11-17; confirm on the vendor's page.

A model on your machine

  • Graphify-Labs/graphify's guide to running a local code knowledge graph with Ollama says an Ollama model on the reader's own computer can handle the documents, papers and the naming of communities. (docs.graphify.com page, read 2026-11-17)
  • Graphify-Labs/graphify's guide to running a local code knowledge graph with Ollama says other servers compatible with the OpenAI API, LM Studio or llama.cpp among them, can be used by setting the OPENAI_BASE_URL and OPENAI_MODEL variables and choosing the openai backend. (docs.graphify.com page, read 2026-11-17)

About the product

  • Graphify-Labs/graphify's page comparing Graphify with Graphify CLI says the open-source package builds the graph on the user's own computer and writes it to a graphify-out/ folder. (docs.graphify.com page, read 2026-11-17)
  • Graphify-Labs/graphify's page on running its MCP server in Docker says the open-source repository includes a Dockerfile that serves graphify-mcp over streamable HTTP, and that agents on the reader's network can query one graph through a mounted graphify-out/ folder. (docs.graphify.com page, read 2026-11-17)
