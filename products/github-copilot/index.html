The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the vendor's page.

Local models

  • GitHub's bring-your-own-key page says Copilot can use models of the user's choice, whether running on the user's machine or hosted by another provider; for Business and Enterprise plans an enterprise or organization policy can turn off local bring-your-own-key in IDEs. (docs.github.com page, read 2026-10-19)

Local and cloud models in one session

  • Copilot CLI can be configured to use models from a chosen LLM provider via BYOK, in addition to GitHub-hosted models, including locally running models like Ollama. (docs.github.com page, read 2026-10-19)

What you set up

  • You set environment variables to define the model provider before launching Copilot CLI. (docs.github.com page, read 2026-10-19)
  • Copilot CLI's page says a model must support tool calling and streaming or the CLI returns an error, and it advises a model with at least 128k tokens of context. (docs.github.com page, read 2026-10-19)

Models from different providers in one session

  • GitHub's page on changing the Copilot Chat model says the model can be switched partway through a chat, and the model switched to then answers later prompts. (docs.github.com page, read 2026-10-23)
  • GitHub's page on changing the Copilot Chat model lists model providers, Anthropic, Gemini and OpenAI among them, as a source from which more models can be added to Copilot Chat. (docs.github.com page, read 2026-10-23)

Several endpoints, built in (no proxy)

  • In GitHub Copilot CLI's bring-your-own-key setup, the required COPILOT_PROVIDER_BASE_URL variable holds the base URL of the model provider's API endpoint. (docs.github.com page, read 2026-10-21)

Plan or account

  • GitHub's page says its local bring-your-own-key mechanism removes the need for GitHub's Copilot API, and describes it as suitable for air-gapped environments and for people without a Copilot subscription. (docs.github.com page, read 2026-10-21)

A separate model for planning and for doing

  • GitHub's page on creating custom agents says a model property in an agent profile can choose which AI model the agent uses when the profile is created and used in Xcode, Eclipse, JetBrains IDEs or VS Code. (docs.github.com page, read 2026-10-23)

Works with other products

  • GitHub's Copilot CLI bring-your-own-key page gives one set of setup steps for OpenAI, Ollama, vLLM and Foundry Local, and for other endpoints that speak the OpenAI Chat Completions API. (docs.github.com page, read 2026-10-19)

About the product

  • GitHub's documentation says the Copilot command-line interface lets the user work with Copilot directly from a terminal. (docs.github.com page, read 2026-10-24)
  • GitHub's documentation says the Copilot cloud agent is able to edit files, and to run tests and linters, in a short-lived cloud development environment rather than the user's local IDE. (docs.github.com page, read 2026-10-24)
