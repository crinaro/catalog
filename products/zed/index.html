The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the vendor's page.

Local models

  • Zed's local-model page lists Ollama, llama.cpp, LM Studio and a local OpenAI-compatible server as local paths for Zed's AI features; its table marks External Agents and Terminal Threads 'Separate config' for each. (zed.dev page, read 2026-10-19)

Cloud models

  • Zed's API-access page has an OpenAI-compatible endpoint section, for a service the user reaches at their own base URL using a model ID and an API key. (zed.dev page, read 2026-10-19)

Local and cloud models in one session

  • After providers are configured, the user can switch between their models with the model selector in Zed's message editor. (zed.dev page, read 2026-10-19)
  • Zed's agent-settings page lists separate model settings for the inline assistant, commit messages, thread summaries, compaction and subagents; for compaction it says to set the compaction model to use a different model than the thread's. (zed.dev page, read 2026-10-19)

What a local model must meet

  • Zed's Agent Panel page treats a model context window under 80000 tokens as too small for automatic compaction; for such a model it shows a banner over the message editor as the thread nears the token limit. (zed.dev page, read 2026-10-19)
  • Agentic editing is enabled by the Agent Panel's support for tool calling. (zed.dev page, read 2026-10-19)

Plan, policy and billing

  • Zed's pricing page says the Personal plan suits users who want an editor with no AI, or who would rather bring their own keys or external agents. (zed.dev page, read 2026-10-23)
  • Zed's pricing page lists, under its Personal plan, which it marks free, unlimited use with your own API keys or with external agents such as Claude Agent and Codex CLI. (zed.dev page, read 2026-10-23)
  • Zed's admin controls page says its organization controls leave out third-party extensions, Terminal Threads, External Agents, gateways, local models and bring-your-own-key setups, because these work apart from Zed's servers. (zed.dev page, read 2026-10-23)
  • Zed's Business overview says the Data & Privacy dashboard is where administrators manage AI and data settings across the organization. (zed.dev page, read 2026-10-23)
  • Zed's Business overview says members cannot individually override the AI and data settings administrators set for the whole organization. (zed.dev page, read 2026-10-23)
  • Zed's Use API Access page counts credits bought from a provider, usage-based billing and top-ups as API access, and says that holds when the reader pays the provider directly. (zed.dev page, read 2026-10-19)
  • Anthropic API credits are separate from Claude Pro and Max subscriptions. (zed.dev page, read 2026-10-19)

A separate model for planning and for doing

  • Zed allows specific model settings for subagents, thread summaries, Git commit generation, and Inline Assistant. (zed.dev page, read 2026-10-19)

About the product

  • Zed's README says that on macOS, Linux and Windows the editor can be downloaded directly or installed through a local package manager. (github.com page, read 2026-10-24)
