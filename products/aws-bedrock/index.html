About the product

  • AWS's data protection page for Bedrock says Bedrock uses Model Deployment Accounts, with one such account per model provider in each AWS Region where Bedrock is available. (docs.aws.amazon.com page, read 2026-11-18)
  • AWS's data protection page for Bedrock says the Model Deployment Accounts belong to, and are run by, the Bedrock service team. (docs.aws.amazon.com page, read 2026-11-18)
  • AWS's data protection page for Bedrock says model providers have no access to the deployment accounts, so they also lack access to Bedrock logs and to what customers send as prompts and receive as completions. (docs.aws.amazon.com page, read 2026-11-18)
