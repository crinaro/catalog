The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the vendor's page.

Local models

  • Kilo Code allows local model execution via Ollama. (kilo.ai page, read 2026-10-20)

One sentence naming both a local and a cloud path

  • Based on their requirements, the customer may pick among cloud providers, local models, and AI gateways. (kilo.ai page, read 2026-10-20)

Models from different providers in one session

  • In Kilo Code, a custom agent's model setting can pin a specific model, written as provider/model, for example anthropic/claude-sonnet-4-20250514. (kilo.ai page, read 2026-10-21)

What a local model must meet

  • A context size of at least 32k is needed for decent results, though memory usage rises and performance may drop as context grows, depending on hardware. (kilo.ai page, read 2026-10-19)
  • Kilo Code's Ollama page says a reader needs a GPU with 24GB or more of VRAM, or a MacBook with 32GB or more of unified memory, to run its two named models, qwen3-coder:30b and devstral:24b, at decent speed. (kilo.ai page, read 2026-10-19)

Plan, policy and billing

  • Kilo Code's plans page names Teams and Enterprise as its paid plans for organizations. (kilo.ai page, read 2026-10-23)
  • Kilo Code's provider page says a new account can start straight away on free models, and credits can be topped up to get premium models. (kilo.ai page, read 2026-10-23)
  • Kilo Code's page on using it for free says free models are supported for coding work and background tasks. (kilo.ai page, read 2026-10-23)
  • Kilo Code's model access controls page says organization owners on the Enterprise plan can block chosen AI models or providers for every team member, and that other plans leave every model and provider open. (kilo.ai page, read 2026-10-23)
  • Kilo Code's model access controls page says a restriction set for the organization cannot be overridden by individual users. (kilo.ai page, read 2026-10-23)
  • Kilo Code's enterprise page says organization administrators can limit BYOK routes, data policies, models and providers across the organization while leaving approved developer workflows unblocked. (kilo.ai page, read 2026-10-23)
  • Kilo Code supports over 30 providers for users who need specific models or want their own API keys. (kilo.ai page, read 2026-10-19)

A separate model for planning and for doing

  • Kilo Code's model selection page says that for local usage the main model can be a direct provider key you bring yourself, or a local one served by Ollama or LM Studio. (kilo.ai page, read 2026-10-23)
  • Kilo Code's model selection page tells local users to set small_model explicitly, to a model from the same provider as their main model. (kilo.ai page, read 2026-10-23)
  • The task tool launches subagents using the Subagent model as the default. (kilo.ai page, read 2026-10-21)

About the product

  • Kilo Code's README describes Kilo Code as an open source coding agent that can be used inside VS Code or JetBrains, or from the command line. (github.com page, read 2026-10-24)
  • Kilo Code's README says Kilo can be run from the web at app.kilo.ai/cloud, with no local machine needed. (github.com page, read 2026-10-24)
