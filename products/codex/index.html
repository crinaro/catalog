The readings behind this page

Our summary of the maker's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the maker's page.

Cloud models

  • Codex's advanced-config page says it has a built-in provider for Amazon Bedrock, and that a custom provider is set by a base URL and related fields; its example defines an LLM proxy, a local Ollama and Mistral. (learn.chatgpt.com page, read 2026-10-19)

What you set up

  • Codex lets the user define extra model providers in config and point the model_provider key at one; the page's example file holds a local Ollama provider beside hosted ones. (learn.chatgpt.com page, read 2026-10-19)
  • For its local-provider mode, Codex lets the user choose the provider for one run or set a default in config; with neither set, the interactive CLI prompts the user to choose and codex exec ends with an error. (learn.chatgpt.com page, read 2026-10-19)

Models from different providers in one session

  • Local Codex clients let you define custom agents whose model configurations and instructions differ from task to task. (learn.chatgpt.com page, read 2026-10-21)

Plan, policy and billing

  • Codex's pricing page, answering what happens at usage limits, says all users can also run extra local chats with an API key, charged at standard API rates. (learn.chatgpt.com page, read 2026-10-23)
  • Codex's pricing page says that with an API key, image generation is priced at API rates and is not counted against the usage limits included with a ChatGPT plan. (learn.chatgpt.com page, read 2026-10-23)
  • Codex's Amazon Bedrock page sends questions about AWS credentials, quotas and billing, among other topics, to the customer's own AWS administrator or to AWS Support. (learn.chatgpt.com page, read 2026-10-23)
  • Codex's models page, in its note on the retirement of gpt-5.4 and gpt-5.4-mini, names gpt-6-luna as the replacement for gpt-5.4-mini and says that on Enterprise and Edu, enabling Luna is something an administrator has to do first. (learn.chatgpt.com page, read 2026-10-19)

A separate model for planning and for doing

  • Codex's subagents page says a subagent takes the model and reasoning effort of its parent agent unless a subagent model or reasoning effort is configured. (learn.chatgpt.com page, read 2026-10-23)
  • Codex's subagents page points to gpt-6-luna as the model to use for lighter subagent work when speed and lower cost matter. (learn.chatgpt.com page, read 2026-10-23)
  • Codex's subagents page advises keeping the main agent focused on the requirements, the decisions and the final outputs. (learn.chatgpt.com page, read 2026-10-21)
  • Codex's subagents page lists a built-in worker agent, described as execution-focused, for implementation and fixes. (learn.chatgpt.com page, read 2026-10-21)
  • Codex's subagents page says a custom agent carries over permissions, provider and MCP servers from its parent, and a custom agent file cannot change them. (learn.chatgpt.com page, read 2026-10-23)

About the product

  • OpenAI's Codex README describes the Codex CLI as OpenAI's coding agent that runs locally on the user's own computer. (github.com page, read 2026-10-24)
  • OpenAI's Codex documentation says Codex can be given coding tasks, from bug investigations to feature builds, to carry out in the cloud. (learn.chatgpt.com page, read 2026-10-24)
