The readings behind this page

Our summary of the maker's pages as of the dates shown on each line (2026-10-20 to 2026-10-24); confirm on the maker's page.

Local models

  • Continue's provider overview lists Ollama as a way to run open-source models locally. (docs.continue.dev page, read 2026-10-20)

Cloud models

  • Continue's provider overview says it supports a wide range of model providers; the table lists Ollama beside hosted providers such as Amazon Bedrock and Google Gemini. (docs.continue.dev page, read 2026-10-20)

Models from different providers in one session

  • Continue lets the customer pick a preferred provider or add several, which enables using distinct models for separate jobs. You can also try a different model if you are unhappy with what the current model gives you. (docs.continue.dev page, read 2026-10-21)

About the product

  • Continue's README says Continue is a coding agent offered as a CLI, a VS Code extension and a JetBrains plugin. (github.com page, read 2026-10-24)
