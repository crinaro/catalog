The readings behind this page

Our summary of the maker's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the maker's page.

Local models

  • OpenCode's page says it supports 75+ LLM providers and running local models. (opencode.ai page, read 2026-10-19)

Cloud models

  • OpenCode's models page says most popular providers come preloaded by default, and a provider whose credentials were added with the connect command is available at startup. (opencode.ai page, read 2026-10-19)

Local and cloud models in one session

  • OpenCode lets the user define specialized agents for specific tasks, and the page's example gives such an agent its own model entry. (opencode.ai page, read 2026-10-19)

What you set up

  • In OpenCode's providers page, the examples for local model servers (Atomic Chat, LM Studio and Ollama among them) say the options.baseURL setting is the endpoint of that local server. (opencode.ai page, read 2026-10-19)
  • OpenCode's models page says a default model is set with the model key in the OpenCode config, written as provider ID and model ID; its example sets a model under the lmstudio provider. (opencode.ai page, read 2026-10-19)

Models from different providers in one session

  • In OpenCode, an agent's model config overrides the model for that agent, which the page says is useful for matching different tasks with models suited to them. (opencode.ai page, read 2026-10-21)

Several endpoints, built in (no proxy)

  • OpenCode lets you change the base URL of any provider through its baseURL option. (opencode.ai page, read 2026-10-21)

What a local model must meet

  • OpenCode's models page says models discovered from vLLM advertise no tool support, because discovery does not report the server flags that switch tool calling on. (opencode.ai page, read 2026-10-23)
  • OpenCode's providers page says models found by vLLM discovery start with tools switched off, because discovery cannot tell whether a model supports tools. (opencode.ai page, read 2026-10-23)
  • OpenCode's models page says that for a model not already in its catalog, it assumes a context limit of 200,000 tokens and an output limit of 32,000 tokens. (opencode.ai page, read 2026-10-23)
  • OpenCode's models page says that for vLLM it takes the context limit from the max_model_len the server reports. (opencode.ai page, read 2026-10-23)

Plan, policy and billing

  • OpenCode's providers page describes OpenCode Go as a subscription you can choose to take, covering coding models that the OpenCode team has tested. (opencode.ai page, read 2026-10-23)
  • OpenCode's providers page says a ChatGPT Pro or Plus plan can replace an OpenAI API key. (opencode.ai page, read 2026-10-23)
  • OpenAI's Sign in with ChatGPT page names OpenCode among four open-source integrations, the others being OpenClaw, Pi and T3. (learn.chatgpt.com page, read 2026-10-23)
  • OpenAI's help article on using a ChatGPT plan in other apps says that, for the open-source tools it supports, availability extends to all ChatGPT users. (help.openai.com page, read 2026-10-23)
  • On OpenCode's providers page, the Cloudflare AI Gateway entry says that with Cloudflare's Unified Billing a reader does not need a separate API key for each provider. (opencode.ai page, read 2026-10-19)

A separate model for planning and for doing

  • The model config lets you override the agent's model. (opencode.ai page, read 2026-10-21)
  • OpenCode's agents page gives, as an example of assigning different models to different agents, a quicker model for planning and a stronger one for implementation. (opencode.ai page, read 2026-10-21)
  • A separate model is configured by the small_model option for lightweight tasks such as title generation. (opencode.ai page, read 2026-10-19)
  • OpenCode provides two primary agents, Build and Plan, as built-in features. (opencode.ai page, read 2026-10-21)

About the product

  • OpenCode's README says OpenCode also comes as a desktop application, which it marks as a beta. (github.com page, read 2026-10-24)
