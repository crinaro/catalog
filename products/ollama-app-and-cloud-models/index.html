The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the vendor's page.

Local models

  • Ollama's documentation home presents a choice between cloud models and running models on your own computer. (docs.ollama.com page, read 2026-10-20)

Cloud models

  • For Claude Desktop, Ollama's integration page says that using a cloud model means signing in to Ollama and enabling cloud models; the next sentence says some models need a paid subscription. (docs.ollama.com page, read 2026-10-20)

Claude Code with a local server

  • Ollama links Claude Code with local and cloud models using its Anthropic-compatible API. (docs.ollama.com page, read 2026-10-21) Caveat: The Claude Code gateway page says Anthropic provides no support when a gateway sends Claude Code's requests to models that are not Claude (code.claude.com page, read 2026-10-21).

What a local model must meet

  • Ollama's page on its Anthropic-compatible API says that, for models it calls compatible, messages, streaming and function calling are supported. (docs.ollama.com page, read 2026-10-21)
  • Ollama's page on its OpenAI-compatible API says that API gives no way to set a model's context size, and tells a reader who needs a different size to create a Modelfile with a num_ctx parameter. (docs.ollama.com page, read 2026-10-19)

About the product

  • Ollama's README says an official Docker image, ollama/ollama, is published on Docker Hub. (github.com page, read 2026-10-24)
  • Ollama's documentation home tells the reader to get Ollama, then run a model on their own computer. (docs.ollama.com page, read 2026-10-24)
