The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-09-24 to 2026-10-24); confirm on the vendor's page.

Local models

  • Not found in the pages we read, for local models: (cursor.com page, read 2026-09-24; cursor.com page, read 2026-10-19)

Cloud models

  • Cursor lets users add their own API keys for the providers its page lists (OpenAI, Anthropic, Google, Azure OpenAI and AWS Bedrock), and those providers' models then appear in the model picker. (cursor.com page, read 2026-09-24)

What you set up

  • Cursor's API keys page says that once a key is added for one of the providers it lists (OpenAI, Anthropic, Google, Azure OpenAI or AWS Bedrock), Cursor applies that key to models from that provider; the page narrows this elsewhere: OpenAI to standard, non-reasoning chat models, and custom keys to chat models only. (cursor.com page, read 2026-09-24)

Models from different providers in one session

  • Cursor's subagents page advises setting a subagent's model to inherit when it should reason as strongly as its parent, and to a specific model ID when it needs that model's capabilities whichever model the parent uses. (cursor.com page, read 2026-10-21)
  • On Cursor's subagents page, a subagent's model setting can be inherit or a specific model ID, which Cursor then uses for that subagent; the page's examples are composer-2 and gpt-5.6-sol. (cursor.com page, read 2026-10-21)
  • Cursor's models page lists GPT-5.6 Sol under OpenAI and Composer 2.5 under Cursor. (cursor.com page, read 2026-10-21)

Plan, policy and billing

  • Cursor's model and integration management page says team settings, Enterprise only, let an admin turn models on or off, choose defaults for newly added providers and models, and decide whether members may bring personal API keys (BYOK). (cursor.com page, read 2026-10-23)
  • Cursor's model and integration management page says Enterprise teams can block their members' use of personal API keys with outside providers, naming OpenAI, Anthropic, Azure and AWS Bedrock. (cursor.com page, read 2026-10-23)
  • On Teams and Enterprise plans, a Cursor Token Rate applies to third-party model requests, at $0.25 per million tokens. (cursor.com page, read 2026-10-19)

About the product

  • Cursor's documentation home invites the reader to get Cursor for their own computer. (cursor.com page, read 2026-10-24)
  • Cursor's cloud agents page says cloud agents run in isolated virtual machines in the cloud rather than on the user's local machine, each with a complete development environment. (cursor.com page, read 2026-10-24)
