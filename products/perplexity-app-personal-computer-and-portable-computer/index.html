Cloud models

  • Perplexity's changelog says Computer tasks can use Perplexity's hosted service together with a model running on the user's own Mac. (www.perplexity.ai page, read 2026-10-20)

What you set up

  • Perplexity's help page gives the Mac steps for a hybrid task: download and open the app, download a local model, open the model selector and choose Hybrid, then choose a local model and a cloud model for the task. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's Personal Computer help page gives the Windows steps for a local model: install the app and sign in, open Settings from the Menu, choose Local Inference, download PPLX 27B under On-device models (Qwen 27B is the alternative for AMD Ryzen AI Max hardware), then pick the model under Local in the composer's model menu; setup needs roughly 20 GB of spare disk space. (www.perplexity.ai page, read 2026-10-22)

Models from different providers in one session

A model on your machine

  • On Mac, any of 3 local models (a Perplexity model, Qwen3.6 35B-A3B or Gemma 4 E4B) downloads in one click without Ollama or manual runtime setup; the page gives 24 GB unified memory as the minimum. (www.perplexity.ai page, read 2026-10-19)
  • Perplexity's help page says that with Portable Computer on Windows and Linux, both the model and the agent run on the device, so a whole task can stay local. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's help page says Windows, Linux and DGX Spark systems run only a single local model at once. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's Portable Computer help page says Portable Computer puts the model and agent of Computer on hardware you own, so a task executes on the device and not in the cloud. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's Personal Computer help page lists the local models by platform: the Perplexity model, Qwen3.6 35B-A3B and Gemma 4 E4B on an Apple silicon Mac; PPLX 27B and Qwen 27B on AMD Ryzen AI Max Windows PCs or a DGX Spark; PPLX 27B on an RTX Windows or Linux PC. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's Portable Computer help page lists PPLX 27B and Qwen 27B for a DGX Spark and for supported Windows and Linux PCs. (www.perplexity.ai page, read 2026-10-22)
  • The product launches with three local models, which are a Perplexity model, Qwen3.6 35B-A3B, and Gemma 4 E4B. (www.perplexity.ai page, read 2026-10-19)

Local and cloud in one session

  • On a Mac with supported hardware, hybrid compute splits each task: cloud models handle reasoning, web search and planning, and a local model on the Mac handles sensitive files and steps. Local models are for Pro, Max and Enterprise subscribers. (www.perplexity.ai page, read 2026-10-19)
  • Perplexity's Portable Computer help page says that in a local task you can allow a single cloud step by approving the prompt Portable Computer shows. (www.perplexity.ai page, read 2026-10-22)

Plan or account

  • Pro, Max, and Enterprise subscribers can access local models. (www.perplexity.ai page, read 2026-10-19)

(www.perplexity.ai page, read 2026-10-22)

Plan, policy and billing

  • Perplexity's blog post on Hybrid compute for Mac says Enterprise subscribers' admins can set rules across the organization that decide which information stays on the Mac, which is masked before cloud use and which needs the user's approval first, and that admins can additionally audit each time information leaves the device. (www.perplexity.ai page, read 2026-10-19)
  • Perplexity's help page says steps the local model handles use no Computer credits, while a cloud step draws on credits the way other Computer work does. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's help page says that for an account an organization manages, local inference is controlled by an administrator: on Windows and Linux the administrator allows or refuses it, and on Mac the administrator can set which material is to remain on the device and which needs your approval before going to the cloud. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's Portable Computer help page says Portable Computer is for Pro and Max subscribers, whether their plan is personal or Enterprise, using a DGX Spark or a supported NVIDIA RTX PC on Windows or Linux. (www.perplexity.ai page, read 2026-10-22)

  • Perplexity's Computer for Enterprise help page says administrators can switch Computer off for the entire organization, at any time. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's firewall-policy help page says Enterprise admins can set the websites and network destinations that Computer's cloud sandbox reaches during a task. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's Model Council help page says Model Council is included with Max and with Enterprise Max, whether on the web or in the iOS app, and that it is not yet offered as its own search mode in the desktop apps or the Android app. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's credits help page says Pro and Max subscribers, including those on Enterprise Pro and Enterprise Max, can get Computer credits. (www.perplexity.ai page, read 2026-10-22)
  • Perplexity's Portable Computer help page says that on an account an organization manages, an administrator might first have to allow local inference before Portable Computer can be used. (www.perplexity.ai page, read 2026-10-22)
