The readings behind this page

Our summary of the maker's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the maker's page.

What you set up

  • Cline's Plan and Act page describes a setting that lets the planning and acting modes use different models. (docs.cline.bot page, read 2026-10-19)
  • For Cline's OpenAI-compatible provider option, the page says to enter the base URL that the chosen provider supplies. (docs.cline.bot page, read 2026-10-19)

What a local model must meet

  • Cline advises keeping tasks focused, noting that smaller context leads to faster responses. (docs.cline.bot page, read 2026-10-19)
  • Cline's local-models page has a Hardware Requirements table: 16-32GB of RAM for small or quantized models, 32-64GB for mid-size coding models, and 64GB or more for bigger models and larger context windows. (docs.cline.bot page, read 2026-10-19)

Plan, policy and billing

  • Cline's provider page names ClinePass, a flat monthly subscription that gives 2-5x the usage of standard API rates on selected open coding models, as the alternative to usage billing. (docs.cline.bot page, read 2026-10-23)
  • Cline's provider page says the Cline provider on usage billing gives pay-per-use access to models, with login included and Cline credits. (docs.cline.bot page, read 2026-10-23)
  • Cline's provider page says free models are tagged FREE in the model selector. (docs.cline.bot page, read 2026-10-23)
  • Cline's remote configuration page says members on Cline Desktop or the CLI are free to pick different providers and MCP servers. (docs.cline.bot page, read 2026-10-23)
  • Cline's remote configuration page says Admins and Owners can choose to stay out of the organization's remote settings from the Account page, which members cannot do. (docs.cline.bot page, read 2026-10-23)
  • Cline's documentation home page lists controls over models and tools for each team among its enterprise features. (docs.cline.bot page, read 2026-10-23)
  • Cline's OpenAI-compatible settings ask for an API key, which you get from the provider you chose. (docs.cline.bot page, read 2026-10-19)

A separate model for planning and for doing

  • Cline's Plan and Act page says Plan mode and Act mode can each be given its own model. (docs.cline.bot page, read 2026-10-19)

About the product

  • Cline's README tagline places Cline, an open source coding agent, in the user's IDE, terminal and desktop. (github.com page, read 2026-10-24)
  • Cline's README lists Ollama and LM Studio as ways to run local models on the user's machine. (github.com page, read 2026-10-24)
  • Cline's README table lists Azure and GCP Vertex in one row, with the entry: all hosted models. (github.com page, read 2026-10-24)
