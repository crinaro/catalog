The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-19 to 2026-10-23); confirm on the vendor's page.

Local models

  • Gemini CLI's configuration reference lists an experimental Gemma model router, off by default, that needs a local endpoint serving Gemma. (github.com page, read 2026-10-19)

Cloud models

  • Gemini CLI's readme describes it as an open-source terminal agent for Gemini and lists three ways to authenticate: a Google account sign-in, a Gemini API key and Vertex AI. (github.com page, read 2026-10-19)

Models from different providers in one session

  • Under agents.overrides in settings.json, Gemini CLI lets you force a specific model and raise the turn limit for a built-in subagent, per the page's example. (github.com page, read 2026-10-21)

Local and cloud in one session

  • Gemini CLI's model routing page says that its local routing mode, marked experimental, once configured has a locally running Gemma model make the routing decisions in place of a hosted model. (github.com page, read 2026-10-23)
  • Gemini CLI's model routing page lists, as an experimental option, that with the Gemma local model router enabled in settings.json the CLI uses the local Gemma model, not Gemini models, to route a request to a suitable model. (github.com page, read 2026-10-23)

Plan, policy and billing

  • Gemini CLI's quotas and pricing page says access to the CLI begins with a free tier. (github.com page, read 2026-10-23)
  • Gemini CLI's quotas and pricing page says a Gemini API key also comes with a free tier. (github.com page, read 2026-10-23)
  • Gemini CLI's quotas and pricing page says that once the initial requests are used up, a person can keep using the CLI by moving to one of the subscriptions it lists under its paid tier. (github.com page, read 2026-10-23)
  • Gemini CLI's authentication page says every free tier account, Gemini Code Assist for individuals among them, counts as an individual Google account, as do the paid Google AI Pro and Ultra subscriptions. (github.com page, read 2026-10-23)
  • Gemini CLI's authentication page says that for most individual Google accounts, free or paid, no Google Cloud project is required for authentication. (github.com page, read 2026-10-23)
  • Gemini CLI's quotas and pricing page says the pay-as-you-go option is reached by logging in with Vertex AI or with a Gemini API key. (github.com page, read 2026-10-23)
  • Gemini CLI's quotas and pricing page lists the cost of using a Gemini API key as varying by pricing tier and by model and token usage. (github.com page, read 2026-10-23)
  • Gemini CLI's quotas and pricing page says that with an API key a person pays per token or per call. (github.com page, read 2026-10-23)

A separate model for planning and for doing

  • Based on Plan Mode status, Gemini CLI switches between Pro and Flash models, using Pro for planning and Flash for implementation. (github.com page, read 2026-10-19)
