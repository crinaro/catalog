LiteLLM

A Python SDK and a proxy server in one repository, the proxy giving applications one OpenAI-shaped address, one set of keys and one budget in front of many model providers.

The readings behind this page

Our summary of the vendor's pages as of the dates shown on each line (2026-10-19 to 2026-10-26); confirm on the vendor's page.

Local models

  • LiteLLM's LM Studio page says it supports all LM Studio models, selected with a model string that starts with lm_studio/. (docs.litellm.ai page, read 2026-10-20)

Cloud models

  • LiteLLM provides a single interface to call over 100 LLM providers, including OpenAI, Anthropic, Gemini, Bedrock, and Azure, using the OpenAI format. (github.com page, read 2026-10-20)

Works with other products

  • LiteLLM supports running Claude Code, Codex, Deep Agents, or OpenCode on any model via the Python SDK. (github.com page, read 2026-10-19)

About the product

  • LiteLLM's README describes LiteLLM as an open source AI gateway for over 100 LLMs and calls it self-hosted. (github.com page, read 2026-10-24)
  • LiteLLM's Ollama page says it supports all Ollama models, lists a running Ollama server as a prerequisite, and every call in its model table sets its address to localhost. (docs.litellm.ai page, read 2026-10-19)
  • LiteLLM's documentation describes its proxy as a gateway you host yourself that speaks the OpenAI API, and shows two ways to start it: the LiteLLM command-line tool or Docker. (docs.litellm.ai page, read 2026-10-26)
  • LiteLLM's documentation describes LiteLLM as an open-source library with one interface for calling more than 100 LLMs, among them OpenAI, Anthropic, Vertex AI and Bedrock. (docs.litellm.ai page, read 2026-10-26)
