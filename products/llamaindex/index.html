Local models

  • LlamaIndex's Ollama example page says local models are served on localhost:11434 while the Ollama app is running, and shows an Ollama class that is given a model name and version. (developers.llamaindex.ai page, read 2026-10-20)

Cloud models

  • LlamaIndex's LLM page says one common interface covers LLM modules whether they originate with OpenAI, Hugging Face or LangChain; the page does not say which of these are hosted. (developers.llamaindex.ai page, read 2026-10-20)
