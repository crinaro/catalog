The readings behind this page

Our summary of the maker's pages as of the dates shown on each line (2026-10-19 to 2026-10-24); confirm on the maker's page.

Local models

  • goose's provider table lists Ollama as a local runner for open-source models; a model must be downloaded and running first. (goose-docs.ai page, read 2026-10-19)
  • In goose Desktop, models already installed locally for Ollama appear in the model dropdown. (goose-docs.ai page, read 2026-10-19)

Local and cloud models in one session

  • goose's multi-model page says the /model command changes models without ending the session, either staying with the current provider or moving to another. (goose-docs.ai page, read 2026-10-19)

What you set up

  • goose Desktop lists providers with a Configure button each, and a provider that is not listed can be added as a custom provider. (goose-docs.ai page, read 2026-10-19)

Models from different providers in one session

  • Focused tasks are delegated to isolated goose instances, and each can run a provider and model of its own. (goose-docs.ai page, read 2026-10-21)

What a local model must meet

  • goose's Qwen 3 blog post says the model, even in a compact form of 8B parameters at 4-bit quantization, was able to call tools with goose. (goose-docs.ai page, read 2026-10-23)
  • goose's blog post on running it with Ollama calls RAM the key requirement, with 32GB a sound starting point for bigger models and outputs. (goose-docs.ai page, read 2026-10-23)
  • goose's blog post on running it with Ollama says that on Windows and Linux, GPU memory matters more for acceleration. (goose-docs.ai page, read 2026-10-23)

Plan, policy and billing

  • goose's providers page says its ChatGPT Codex provider requires a ChatGPT Plus or Pro subscription. (goose-docs.ai page, read 2026-10-19)
  • OpenAI's Sign in with ChatGPT page on ChatGPT Learn lists partner apps that use a ChatGPT plan, among them Amp Code, Devin, Kilo Code, Notion, Vercel and Warp, apps that offer sign-in only, and four open-source integrations, namely OpenClaw, OpenCode, Pi and T3; none of its lists names goose. (learn.chatgpt.com page, read 2026-10-23)
  • OpenAI's help article on using a ChatGPT plan in other apps says OpenAI has begun with a limited number of partners, sends open-source developers to its developer documentation and asks commercial partners to use an interest form. (help.openai.com page, read 2026-10-23)
  • OpenAI's Sign in with ChatGPT developer overview says an open-source app can ask a person for permission to draw on their ChatGPT plan for eligible API requests, that its docs cover apps that are open source or hosted locally, and that an app that is paid or hosted remotely should apply through an interest form. (developers.openai.com page, read 2026-10-23)
  • OpenAI's Sign in with ChatGPT Terms say an app may use a person's ChatGPT plan only for the app that person connected, may not hand out general API access to other tools, and must let people use their plan through it without paying the app. (openai.com page, read 2026-10-23)
  • goose's providers page says its GCP Vertex AI entry limits the models that can be chosen according to an organization policy, where one has been set. (goose-docs.ai page, read 2026-10-19)

A separate model for planning and for doing

  • goose's page on using multiple models describes subagents as isolated goose instances to which focused tasks are delegated, each able to use a provider and model of its own. (goose-docs.ai page, read 2026-10-21)
  • GOOSE_SUBAGENT_MODEL and GOOSE_SUBAGENT_PROVIDER define the subagent model and provider defaults, with recipe settings taking precedence over both. (goose-docs.ai page, read 2026-10-21)

Works with other products

  • LM Studio allows local execution of open-source models via an OpenAI-compatible API server. (goose-docs.ai page, read 2026-10-19)

About the product

  • goose's README describes goose as an all-purpose AI agent running on the user's own machine. (github.com page, read 2026-10-24)
  • goose's providers page says the OpenAI provider also takes OpenAI-compatible endpoints, with self-hosted LLaMA, vLLM and KServe given as examples. (goose-docs.ai page, read 2026-10-24)
  • goose's providers page lists an OpenAI provider offering gpt-4o and o1, among other advanced language models. (goose-docs.ai page, read 2026-10-24)
